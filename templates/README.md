# Templates

Templates para iniciar novos projetos Power BI com estrutura, convenções e parâmetros consistentes.

## Disponíveis

- `semantic-model-starter/`: modelo semântico TMDL mínimo para cenários sem relatório local.
- `pbip-starter/`: projeto completo com `.pbip`, relatório PBIR e modelo semântico TMDL local.

O template base deve permanecer neutro em relação ao domínio de negócio.

## Regra de consumo

Copie o template para o repositório consumidor e renomeie os artefatos de forma consistente. O código compartilhado e as convenções continuam evoluindo neste repositório; regras de negócio específicas permanecem no consumidor.
